Line weight, one slider away.سُمك الخط بحركة واحدة.

Many icon sets arrive "outlined": every line has been turned into a filled shape, so its thickness is frozen. This Figma plugin turns those shapes back into real strokes you can edit again.تصل كثير من مجموعات الأيقونات «محوّلة إلى أشكال»: كل خط فيها صار شكلًا مملوءًا، فتجمّد سُمكه. تعيد هذه الإضافة لـ Figma تلك الأشكال إلى خطوط حقيقية يمكنك تعديلها من جديد.

01 / Before and after01 / قبل وبعد

From frozen shapes to living lines.من أشكال جامدة إلى خطوط حيّة.

Outlined icons in Figma are a closed shape around each line. Rebuilt as real strokes, the same icons can change weight again.الأيقونات المحوّلة في Figma شكل مغلق حول كل خط، وحين تُعاد بناؤها كخطوط حقيقية يعود سُمكها قابلًا للتغيير.

02 / How it works02 / طريقة العمل

Select, run, adjust.حدّد، شغّل، عدّل.

Built for designers who receive icon sets they can't edit, or need one set in several weights.صُممت للمصممين الذين تصلهم مجموعات أيقونات لا يمكن تعديلها، أو يحتاجون المجموعة نفسها بأكثر من سُمك.

1

Select your iconsحدّد أيقوناتك

Pick one icon or a whole set of outlined icons on your Figma canvas.اختر أيقونة واحدة أو مجموعة كاملة من الأيقونات المحوّلة على لوحة Figma.

2

Run the pluginشغّل الإضافة

It finds the centre line inside each shape and rebuilds it as a real stroke.تجد الإضافة الخط الأوسط داخل كل شكل، وتعيد بناءه كخط حقيقي.

3

Set the weightاضبط السُمك

Change the stroke width like any normal line, for one icon or the whole set.غيّر سُمك الخط كأي خط عادي، لأيقونة واحدة أو للمجموعة كلها.
