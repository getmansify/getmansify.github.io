Download every Google Flow result, named and in order.حمّل كل نتائج Google Flow بأسماء مرتّبة.

In short: in Google Flow you download each image or video from its own menu, one at a time, and the file gets a generic name. With Prompt Batch, every result of your list is downloaded the moment it is ready, at the size you chose, and saved as 01_name.jpg, 02_name.mp4… in the order of your file.

This guide covers the download side of a run: how files are named, where they go, and which sizes to pick. New to Prompt Batch? Start with Run many prompts in Google Flow at once.

1. Name your rows

Add a name column to your file. That name is used twice: as the file name on your computer, and as the result's title inside Flow, so you can find it again in the project.

prompt,type,name
"A quiet harbour at dawn, soft mist",image,harbour
"The same harbour at night",image,harbour_night
"Slow push-in over the harbour",video,harbour_clip

No name column? The file name is made from the first words of the prompt (up to six words), so A quiet harbour at dawn becomes 01_a-quiet-harbour-at-dawn.jpg. Arabic names and prompts work too.

2. Pick the folder

In the panel's Download section, Folder in Downloads is the folder your files go to. It is Prompt Batch unless you change it.

  • When you load a file, a subfolder with that file's name is added by itself, so each list keeps its own folder. Pasted prompts go straight into the main folder.
  • Type / to make your own subfolders, for example Prompt Batch/Ads.
  • The line Saved in: under the field shows the full path before you start.

3. Pick the sizes

SettingChoicesGood to know
Image size1K, 2K, 4K2K and 4K are upscaled by Flow, so they take a little longer.
Video size720p, 1080p, GIF1080p is upscaled by Flow too. GIF makes a small animated file.
Seconds between downloads5 or more (10 by default)Used when a prompt makes more than one result.

Flow sometimes fails to upscale after many in a row. Prompt Batch then tries again a minute later. If it fails twice, it saves Flow's original size instead (1K image or 720p video), adds that size to the name (_1K for an image, _720p for a video), shows a yellow note on that row, and carries on.

4. Run it

Check that Download results automatically is on (it is by default), then press Start. For each row, Prompt Batch waits for the result, renames it in Flow, downloads it, and only then moves to the next prompt.

The first time, Chrome may ask to allow several downloads from flow.google.com. Allow it, or the files after the first one will not be saved.

What you get

For a file called harbour-ad.csv, with the default folder:

Downloads/
└─ Prompt Batch/
   └─ harbour-ad/
      ├─ 01_harbour.jpg
      ├─ 02_harbour_night_1.jpg
      ├─ 02_harbour_night_2.jpg
      └─ 03_harbour_clip.mp4

The number is the row's place in your file, so the files sort in the same order as your list. When one prompt makes several results, they get _1, _2… at the end.

Tips

  • Keep names short and different. They become file names and Flow titles, and a later row can use them as a reference or start picture.
  • Pick the size before you start. The size is chosen when each file is downloaded, not after the run.
  • One file per project. Because each loaded file gets its own subfolder, giving your files clear names (for example day-1.csv, day-2.csv) keeps your downloads tidy.
  • Need only the results in Flow? Switch off Download results automatically. Everything is still made and named in your Flow project.

Questions

Can it download results I made in Flow before, by hand?

No. Prompt Batch saves the results it makes during a run. Results you made earlier stay in your Flow project, where you can download them from each one's menu.

Why does a file end in "_1K" or "_720p"?

Flow could not upscale it to the size you chose, even after a second try a minute later, so Prompt Batch saved the original size instead of nothing. The row shows a yellow note.

Only the first file was saved. Why?

Chrome blocks several downloads from one site until you allow them. Allow multiple downloads for flow.google.com when Chrome asks, or in Chrome's site settings, and run the missing rows again.

Do Arabic names work?

Yes. Arabic letters are kept in file names and in Flow titles.

باختصار: في Google Flow تحمّل كل صورة أو فيديو من قائمته الخاصة، واحدًا تلو الآخر، ويأخذ الملف اسمًا عامًا. ومع Prompt Batch تُحمَّل كل نتيجة في قائمتك لحظة جاهزيتها، بالحجم الذي اخترته، وتُحفظ باسم مثل 01_name.jpg و02_name.mp4… بترتيب ملفك.

يشرح هذا الدليل جانب التحميل في التشغيل: كيف تُسمّى الملفات، وأين تُحفظ، وأي الأحجام تختار. جديد على Prompt Batch؟ ابدأ بشرح شغّل أوامر كثيرة في Google Flow دفعة واحدة.

1. سمِّ الصفوف

أضف إلى ملفك عمود name. يُستخدم هذا الاسم مرتين: اسمًا للملف على جهازك، وعنوانًا للنتيجة داخل Flow، فتجدها بسهولة في المشروع.

prompt,type,name
"A quiet harbour at dawn, soft mist",image,harbour
"The same harbour at night",image,harbour_night
"Slow push-in over the harbour",video,harbour_clip

ليس في ملفك عمود name؟ يُصنع اسم الملف من أول كلمات الأمر (حتى ست كلمات)، فيصبح الأمر A quiet harbour at dawn ملفًا باسم 01_a-quiet-harbour-at-dawn.jpg. وتعمل الأسماء والأوامر العربية أيضًا.

2. اختر المجلد

في قسم التنزيل في اللوحة، حقل «المجلد داخل التنزيلات» هو المجلد الذي تُحفظ فيه ملفاتك، واسمه Prompt Batch ما لم تغيّره.

  • عندما تحمّل ملفًا، يُضاف تلقائيًا مجلد فرعي باسم ذلك الملف، فيبقى لكل قائمة مجلدها. أما الأوامر الملصوقة فتُحفظ في المجلد الرئيسي مباشرة.
  • اكتب / لتنشئ مجلدات فرعية بنفسك، مثل Prompt Batch/Ads.
  • يعرض سطر «تُحفظ في:» تحت الحقل المسار الكامل قبل أن تبدأ.

3. اختر الأحجام

الإعدادالخياراتمن المفيد أن تعرف
جودة الصور1K، 2K، 4Kيكبّر Flow صور 2K و4K، فتأخذ وقتًا أطول قليلًا.
جودة الفيديو720p، 1080p، GIFيكبّر Flow فيديو 1080p أيضًا. وخيار GIF يصنع ملفًا متحركًا صغيرًا.
ثوانٍ بين كل تنزيل5 أو أكثر (10 افتراضيًا)تُستخدم عندما يصنع الأمر أكثر من نتيجة.

أحيانًا يفشل Flow في تكبير النتائج بعد عدد كبير منها. عندها تحاول الإضافة مرة أخرى بعد دقيقة. وإذا فشلت المحاولتان، تحفظ الحجم الأصلي في Flow (صورة 1K أو فيديو 720p)، وتضيف هذا الحجم إلى الاسم (_1K للصورة، و_720p للفيديو)، وتعرض ملاحظة صفراء على ذلك الصف، ثم تكمل.

4. شغّل القائمة

تأكد أن خيار «تنزيل النتائج تلقائيًا» مفعّل (وهو مفعّل افتراضيًا)، ثم اضغط «ابدأ». في كل صف تنتظر الإضافة النتيجة، وتسمّيها في Flow، وتحمّلها، ثم تنتقل إلى الأمر التالي.

في أول مرة، قد يسألك Chrome عن السماح بتنزيل عدة ملفات من flow.google.com. اسمح بذلك، وإلا فلن تُحفظ الملفات بعد الملف الأول.

ماذا تحصل عليه

لملف اسمه harbour-ad.csv، مع المجلد الافتراضي:

Downloads/
└─ Prompt Batch/
   └─ harbour-ad/
      ├─ 01_harbour.jpg
      ├─ 02_harbour_night_1.jpg
      ├─ 02_harbour_night_2.jpg
      └─ 03_harbour_clip.mp4

الرقم هو ترتيب الصف في ملفك، فتظهر الملفات بنفس ترتيب قائمتك. وإذا صنع الأمر الواحد أكثر من نتيجة، يُضاف إلى آخر الاسم _1 و_2…

نصائح

  • اجعل الأسماء قصيرة ومختلفة. فهي تصبح أسماء الملفات وعناوين النتائج في Flow، ويستطيع صف لاحق أن يستخدمها مرجعًا أو صورة بداية.
  • اختر الحجم قبل أن تبدأ. يُحدَّد الحجم عند تنزيل كل ملف، لا بعد انتهاء التشغيل.
  • ملف لكل مشروع. لأن كل ملف تحمّله يأخذ مجلده الفرعي، فإن الأسماء الواضحة لملفاتك (مثل day-1.csv وday-2.csv) تبقي تنزيلاتك مرتّبة.
  • تريد النتائج في Flow فقط؟ أوقف خيار «تنزيل النتائج تلقائيًا»، فيُصنع كل شيء ويُسمّى في مشروعك على Flow دون تنزيل.

أسئلة

هل تحمّل نتائج صنعتها في Flow بيدي من قبل؟

لا. تحفظ Prompt Batch النتائج التي تصنعها أثناء التشغيل. أما النتائج التي صنعتها من قبل فتبقى في مشروعك على Flow، ويمكنك تحميلها من قائمة كل نتيجة.

لماذا ينتهي اسم ملف بـ«_1K» أو «_720p»؟

لم يستطع Flow تكبيره إلى الحجم الذي اخترته، حتى بعد محاولة ثانية بعد دقيقة، فحفظت الإضافة الحجم الأصلي بدل ألا تحفظ شيئًا. ويعرض الصف ملاحظة صفراء.

حُفظ الملف الأول فقط. لماذا؟

يمنع Chrome تنزيل عدة ملفات من موقع واحد حتى تسمح بذلك. اسمح بتنزيل عدة ملفات من flow.google.com عندما يسألك Chrome، أو من إعدادات الموقع في Chrome، ثم شغّل الصفوف الناقصة مرة أخرى.

هل تعمل الأسماء العربية؟

نعم. تبقى الحروف العربية في أسماء الملفات وفي عناوين النتائج داخل Flow.
