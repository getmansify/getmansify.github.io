Many Veo videos, one file.فيديوهات Veo كثيرة، من ملف واحد.

In short: Google Flow makes Veo videos one prompt at a time. To make many, write one video per row in a CSV or Excel file and load it in Prompt Batch, a Chrome extension. It sends each prompt in your own Flow project, waits for the video, names it and downloads it. A row can be a video from text, or a picture you already have brought to life with start_image.

Videos take longer than images and use your Flow credits, so this guide also shows how to check the cost before you start and how to test a small batch first.

Three kinds of video rows

You wantWrite the row like this
A video from text onlytype = video and a prompt.
To animate a picture you already uploaded to the projectstart_image = the picture's name in Flow. The row becomes a video by itself.
To make a picture, then animate itOne image row with a name, then a video row whose start_image is that name. The picture is made first, then used.

The third kind is the most useful for a series: make every scene as a picture first, check that they look right together, then animate them in the same file.

The file

A header row, then one video per row. Only prompt is required. This example makes one video from text, then two pictures, then animates each picture:

prompt,type,aspect,name,start_image,resolution,duration
"A paper boat sailing down a rainy street, close-up, soft light",video,16:9,boat_clip,,720p,8
"A lighthouse on a cliff at sunset, painted style",image,16:9,lighthouse,,,
"The same lighthouse at night in a storm, painted style",image,16:9,lighthouse_storm,,,
"Slow push-in, waves crash below, light beam turns",,16:9,lighthouse_clip,lighthouse,720p,8
"Rain lashes the glass, the beam sweeps across the sea",,16:9,storm_clip,lighthouse_storm,720p,8
  • name becomes the file name and the result's name inside Flow, so you can find it later or use it in another file.
  • start_image can point at a picture already in the project, or at the name of an earlier row in the same file.
  • resolution and duration are optional. Leave them empty to keep Flow's current setting.
  • Up to 50 rows per file. For a longer series, split it into several files.

Want an AI tool to write the file for you? The panel has a ready prompt for that under ⚙ → Tips & templates: paste it into your AI tool with your idea and save the answer as a .csv file.

Video settings

  • Model: by default the panel picks the Flow video model that costs the fewest credits. Choose another one in the panel, or set a model column for single rows.
  • Shape: aspect sets 16:9 for YouTube or 9:16 for Shorts, Reels and TikTok.
  • Length and quality: duration (in seconds) and resolution, from the options Flow offers for the model you use.
  • Cost: above the Start button the panel shows how many videos the file will make and about how many credits they will use.

Run it

  1. Open your Flow project, then open the Prompt Batch side panel from Chrome's toolbar.
  2. Drop your file on the panel. If a start_image names a picture that is not in the project, the panel tells you before anything is made.
  3. Press Start and confirm the credits. Prompt Batch sends each prompt, sets the start picture when there is one, waits for the video and downloads it.
  4. Keep the Flow tab open. It can stay in the background while you do other things.

If one row fails, it is marked and the next one starts. At the end you get a summary of what succeeded and what failed, and pressing Start again makes only the rows that are missing.

Tips

  • Test two or three rows first. Fix the prompts before you spend credits on fifty videos.
  • Pictures first, videos after. Pictures are cheaper. Check that your scenes look right, then animate them.
  • Describe the motion, not the scene. When you animate a picture, the scene is already there. Say what moves and how the camera moves: "slow push-in", "locked-off camera", "steam rises".
  • Keep a calm pace. Run one file at a time and rest between long files. See Flow says "requesting generations too quickly".

Questions

Does it use my Flow credits?

Yes. Prompt Batch works in your own Flow account and uses your own credits, exactly as if you typed each prompt yourself. The panel asks you to confirm before a run with videos starts.

Can I mix images and videos in one file?

Yes. Each row sets its own type, so one file can make the pictures and then the videos that animate them.

Can I try it for free?

Yes. Your first 8 results are free, with every feature included. The videos still use your own Flow credits.

Is Prompt Batch made by Google?

No. It is an independent tool by Mansify, not made, endorsed or supported by Google. You are responsible for following Google's terms.

الملف

صف للعناوين، ثم فيديو واحد في كل صف. والعمود المطلوب الوحيد هو prompt. يصنع هذا المثال فيديو من نص، ثم صورتين، ثم يحرّك كل صورة منهما:

prompt,type,aspect,name,start_image,resolution,duration
"A paper boat sailing down a rainy street, close-up, soft light",video,16:9,boat_clip,,720p,8
"A lighthouse on a cliff at sunset, painted style",image,16:9,lighthouse,,,
"The same lighthouse at night in a storm, painted style",image,16:9,lighthouse_storm,,,
"Slow push-in, waves crash below, light beam turns",,16:9,lighthouse_clip,lighthouse,720p,8
"Rain lashes the glass, the beam sweeps across the sea",,16:9,storm_clip,lighthouse_storm,720p,8
  • عمود name يصبح اسم الملف واسم النتيجة داخل Flow، فتجدها بسهولة لاحقًا أو تستخدمها في ملف آخر.
  • عمود start_image يمكن أن يشير إلى صورة موجودة في المشروع، أو إلى اسم صف سابق في الملف نفسه.
  • عمودا resolution وduration اختياريان. اتركهما فارغين لتبقى إعدادات Flow الحالية.
  • يتسع الملف لـ 50 صفًا. وللسلاسل الأطول، قسّمها على عدة ملفات.

هل تريد أن تكتب أداة ذكاء اصطناعي الملف لك؟ في اللوحة أمر جاهز لذلك تحت ⚙ ← نصائح ونماذج: الصقه في أداتك مع فكرتك، واحفظ الإجابة في ملف ‎.csv.

إعدادات الفيديو

  • النموذج: تختار اللوحة تلقائيًا نموذج الفيديو الأقل استهلاكًا للوحدات في Flow. ويمكنك اختيار غيره من اللوحة، أو تحديده لصفوف معيّنة بعمود model.
  • المقاس: عمود aspect يحدد 16:9 ليوتيوب، أو 9:16 للمقاطع القصيرة على Shorts وReels وTikTok.
  • المدة والجودة: عمود duration بالثواني، وعمود resolution، من الخيارات التي يتيحها Flow للنموذج الذي تستخدمه.
  • التكلفة: فوق زر «ابدأ» تعرض اللوحة عدد الفيديوهات التي سيصنعها الملف، وعدد الوحدات التي ستستهلكها تقريبًا.

التشغيل

  1. افتح مشروعك في Flow، ثم افتح اللوحة الجانبية لـ Prompt Batch من شريط أدوات Chrome.
  2. أفلت ملفك في اللوحة. وإذا أشار عمود start_image إلى صورة غير موجودة في المشروع، تخبرك اللوحة قبل أن يُصنع أي شيء.
  3. اضغط «ابدأ» ووافق على الوحدات. ترسل Prompt Batch كل أمر، وتضع صورة البداية إن وُجدت، وتنتظر الفيديو ثم تحمّله.
  4. أبقِ تبويب Flow مفتوحًا. ويمكن أن يبقى في الخلفية وأنت تعمل على شيء آخر.

إذا فشل صف، يُعلَّم ويبدأ الصف التالي. وفي النهاية يظهر ملخص بما نجح وما فشل، وإذا ضغطت «ابدأ» مرة أخرى فلن تُصنع إلا الصفوف الناقصة.

نصائح

  • جرّب صفّين أو ثلاثة أولًا. أصلح الأوامر قبل أن تنفق وحداتك على خمسين فيديو.
  • الصور أولًا ثم الفيديوهات. الصور أرخص. تأكد أن المشاهد مناسبة، ثم حرّكها.
  • صِف الحركة لا المشهد. عندما تحرّك صورة، يكون المشهد موجودًا بالفعل. فاذكر ما الذي يتحرك وكيف تتحرك الكاميرا، مثل: «slow push-in» أو «locked-off camera» أو «steam rises».
  • حافظ على إيقاع هادئ. شغّل ملفًا واحدًا في كل مرة، واسترح بين الملفات الطويلة. واقرأ رسالة «requesting generations too quickly» في Flow.

أسئلة

هل تستخدم وحداتي في Flow؟

نعم. تعمل Prompt Batch داخل حسابك على Flow وتستخدم وحداتك، تمامًا كما لو كتبت كل أمر بنفسك. وتطلب اللوحة موافقتك قبل أن يبدأ تشغيل فيه فيديوهات.

هل يمكنني الجمع بين الصور والفيديوهات في ملف واحد؟

نعم. يحدد كل صف نوعه في عمود type، فيمكن لملف واحد أن يصنع الصور ثم الفيديوهات التي تحرّكها.

هل يمكنني تجربتها مجانًا؟

نعم. أول 8 نتائج مجانية، مع كل المزايا. لكن الفيديوهات تستهلك وحداتك في Flow.
