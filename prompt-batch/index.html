How it works

Three steps. It works in your own Flow account and uses your own credits, just as if you did it by hand.

1

Load your prompts

Drop an Excel, CSV or text file into the side panel, or paste one prompt per line. Each row can set type, aspect ratio, count, model and reference picture.

2

Open a Flow project

Open your project in Google Flow in the same tab. The panel checks that your reference pictures are there and skips rows you already made.

3

Press Start

Prompt Batch sends each prompt, waits for the result, renames it in your project and downloads it to the folder you choose.

Made for long lists

Up to 50 prompts per file, at a calm, human pace, with a live status line and a summary at the end.

Images and videos

Image or video per row, aspect ratio, 1–4 results, model, video resolution and length.

Safe by design

At least 10 seconds between prompts, one failed row never stops the rest, and it stops on its own if Flow reports unusual activity.

8 languages

English, Arabic, Spanish, Portuguese, French, Hindi, Indonesian and Turkish, in light or dark theme.

Questions

Does it use my Flow credits?

Yes. It works in your own Flow account and uses your own credits, exactly as if you typed each prompt yourself. The panel shows how many images, videos and credits a run will use before it starts.

Does it collect my data?

No. Everything stays in your browser. Prompt Batch has no server. If you buy Pro, it sends only your licence key to Lemon Squeezy to check it. Read the privacy policy.

Can I use one key on more than one computer?

Yes, on up to 2 computers that belong to you. Please don't share your key; see the licence terms.

I lost my licence key.
