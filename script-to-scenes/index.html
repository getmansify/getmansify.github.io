From script to scenes.من النص إلى المشاهد.

Paste the script of your video. It is split into short scenes, each with a ready prompt, and your characters and places are described the same way in every scene, so they keep their look. You get one file you can run in Google Flow.الصق نص الفيديو، فيُقسَّم إلى مشاهد قصيرة لكل منها أمر جاهز، وتُوصف شخصياتك وأماكنك بالطريقة نفسها في كل مشهد فيبقى شكلها ثابتًا. وتحصل على ملف واحد تشغّله في Google Flow.

01 / The problem01 / المشكلة

A long video is fifty prompts.الفيديو الطويل خمسون أمرًا.

Each AI clip lasts a few seconds, so a story video needs many scenes. Writing them by hand takes hours, and the hero rarely looks the same twice.كل مقطع بالذكاء الاصطناعي يستمر بضع ثوانٍ، فيحتاج فيديو القصة إلى مشاهد كثيرة. كتابتها يدويًا تأخذ ساعات، ونادرًا ما تبدو الشخصية نفسها مرتين.

02 / How it would work02 / طريقة العمل المقترحة

Paste, check, run.الصق، راجع، شغّل.

Made for creators of story, history and explainer videos built with Veo in Google Flow.صُممت لصنّاع فيديوهات القصص والتاريخ والشرح الذين يعملون بـ Veo في Google Flow.

1

Paste your scriptالصق نصّك

Any length, in English or Arabic. Choose the style and how long each clip should be.بأي طول، بالعربية أو الإنجليزية. اختر الأسلوب ومدة كل مقطع.

2

Check the scenesراجع المشاهد

See every scene and its prompt. Fix a character once and every scene follows.شاهد كل مشهد وأمره. عدّل الشخصية مرة واحدة فتتبعها كل المشاهد.

3

Run it in Flowشغّله في Flow

Download a CSV or Excel file and run it with Prompt Batch, or copy any prompt by hand.نزّل ملف CSV أو Excel وشغّله بـ Prompt Batch، أو انسخ أي أمر يدويًا.
